关机

按住电源键+音量-，进入恢复紫色界面

准备

  1. 下载 MindTheGapps – Android 15（LineageOS 22）/ ARM64（建议最小包）。
  2. 准备好 platform-tools（adb.exe 所在目录），并把 GApps 放到一个好找的路径（例如 C:\Users\你\Downloads\MindTheGapps-15.0.0-arm64-xxxx.zip）。

刷入步骤（Windows）

  1. 进 Lineage Recovery

    • 电脑执行 adb reboot recovery，或按键进恢复。
    • 在手机恢复界面点：Apply update → Apply from ADB（进入 sideload 等待）。

  2. （已开过机才需要）恢复出厂

    • 在恢复主菜单：Factory reset → Format data/factory reset → 回到主菜单，再点 Apply from ADB。
    • 这是因为你已开机过，官方明确“开机后想装 GApps，必须先清数据”。

  3. Windows 端喂包（sideload）

    在 platform-tools 目录打开命令行：

  4. 小提示：电脑端进度显示到 47% 就不动是正常的，后续验证/写入都在手机上进行，请以手机恢复界面的提示为准。

  5. 重启系统

    恢复主菜单 → Reboot system now → 首次开机向导里登录 Google 账号即可。
