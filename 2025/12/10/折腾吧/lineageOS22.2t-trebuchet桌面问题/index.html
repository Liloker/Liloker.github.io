lineageOS22-Trebuchet崩溃修复

发表于2025-12-10|更新于2025-12-09|折腾吧
|总字数:622|阅读时长:2分钟|浏览量:

资源清单

链接 https://github.com/LawnchairLauncher/lawnchair/releases/tag/v15.0.0-beta1

不要下载nightly版本

一、先把系统桌面（Trebuchet/Launcher3）拉起来并设为默认

Trebuchet 基于 AOSP 的 Launcher3（很多构建包名就是 com.android.launcher3；Quickstep 是其手势/最近任务实现）。

• set-home-activity 是官方提供的设置默认桌面的 CLI 接口；am start … HOME 用于拉起主屏

二、卸载不合格的第三方桌面（当时的 nightly/debug 包）

（-k –user 0 解决“仅对主用户安装记录”导致的卸载失败；adb/pm 为官方包管理与设备交互工具。）

三、安装“具备 HOME 资格”的发布版启动器并设为默认

夜ly/CI 包可能不声明 MAIN+HOME 入口而无法成为默认桌面；发布版（例如 Lawnchair 15 Beta / Nova）包含正确入口。

  1. 安装 APK（以 Lawnchair 15 为例）
  1. 查出它的 HOME 入口组件名（务必用实际包名，如 app.lawnchair）：
  1. 设为默认主屏，并拉起：

四、验证当前默认桌面

adb shell cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME

五、（可选）遇到“拒绝授予 HOME 角色”时的定位

  • 你之前的报错行：Package does not qualify for the role … HOME，说明应用不具备角色资格（常见于 nightly/debug 包）。

  • 可用日志定位：

备注：也可以用 RoleManager 授予默认桌面（目标包需合格）：

adb shell cmd role add-role-holder android.app.role.HOME app.lawnchair。若失败，多半是包不合格或崩溃。

就这么多：A 先稳住 Launcher3 → B 卸掉不合格包 → C 安装发布版并用 set-home-activity 指定 → D 用 resolve-activity 验证。这套在你机子（LOS 22.2 / OP6）已验证可复用。需要我把它做成一页 PDF 速查表也可以说一声。
