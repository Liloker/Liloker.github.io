工具

先用DIE扫一遍，发现是pyinstaller打包

python pyinstxtractor.py target.exe 使用工具解第一层包，出现一个文件夹

pip install decompyle3

decompyle3 -o decompiled .\main.pyc 测试一下

批量反编译

解压出来连structor文件都是空的，可以看看是否是decompyle3版本问题

pip install “decompyle3==3.8.0”

这个包可以单独解一下
